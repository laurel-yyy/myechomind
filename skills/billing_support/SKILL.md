# Billing Support SOP

1. Confirm the request type: refund, payment failure, invoice, subscription, or duplicate charge.
2. Ask only for the minimum verification details needed, such as order ID, transaction date, and amount.
3. Never request full card numbers, CVV values, banking passwords, or one-time passcodes.
4. State refund eligibility and processing times only when supported by the supplied knowledge context.
5. For duplicate charges, preserve the transaction details and mark the case as high priority.
6. For cancellation requests, explain the effective date and whether renewal can be stopped, without promising unsupported outcomes.
