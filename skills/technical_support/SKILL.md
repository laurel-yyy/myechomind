# Technical Support SOP

1. Confirm the affected product, platform, and exact symptom.
2. Preserve any error code verbatim and request a timestamp if one is available.
3. Recommend safe, reversible steps first: refresh, retry, sign out and sign in, or update the app.
4. Never request passwords, authentication tokens, full payment details, or other secrets.
5. Do not claim that an incident is resolved without evidence from the available context.
6. Escalate high-impact outages, repeated crashes, and account-access failures after basic diagnostics.
